# References

This folder holds the works cited by the thesis, one file per BibTeX key (`<bibkey>.pdf`).
The keys match the `\bibitem` entries of the thesis bibliography.

Totals: 61 cited works. 47 are included as PDF, 4 are websites or software
with no PDF, and 10 are not freely available (paywalled papers and printed books), so only
their citation and link are listed.

Only freely available copies were collected: arXiv, ACL Anthology, CIDR, and pages hosted by the
authors or their institutions. Where the arXiv version is included, it may differ slightly from the
published version cited in the thesis. `prometheus2025.pdf` is arXiv version 1, whose title matches the
citation (later arXiv versions use a different title).
